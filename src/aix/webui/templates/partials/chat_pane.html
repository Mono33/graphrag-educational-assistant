{# Live chat stream pane (CORE 2 #6.6 P2 phase 2). Rendered as part of ``partials/chat_conversation.html`` whenever ``lesson.status == "running"``. The conversation partial is itself returned by POST /run and inlined by lesson_show.html, so this pane enters the DOM when: - the user submits the chat-input form on a draft lesson, - the user clicks "Rigenera" / "Riprova" on a terminal lesson, or - the user reloads ``/webui/lesson/{id}`` mid-run (re-attaches to the in-flight stream). htmx-SSE wiring: - sse-connect on this root opens the EventSource as soon as the pane enters the DOM. - sse-close="end" guarantees the EventSource gets eventSource.close()'d when the server emits its final ``event: end`` marker, preventing the browser's default 3-second auto-reconnect that would otherwise replay the whole run. - sse-swap="card,final,error" with hx-swap="beforeend" on #chat-cards means every per-agent event APPENDS a fresh card. The 'final' event appends the lesson card, 'error' appends the error card. Writer-pending cards carry an id="writer-card-rev{N}" so the matching 'card' event with hx-swap-oob="outerHTML" replaces them in place when the writer finishes. Required context: lesson Lesson ORM (for the SSE URL) #}
